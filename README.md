# Умный подбор event-подрядчиков (Хакатон-задача #79-lite)

## Что делает проект
Сервис представляет собой интеллектуальный агрегатор event-подрядчиков в Казахстане. Вместо выдачи длинного сухого каталога, система принимает параметры заказа (город, дата, тип мероприятия, бюджет, категория) и возвращает до 3 наиболее подходящих карточек подрядчиков. Главная ценность сервиса — генерация осмысленного, персонализированного объяснения от ИИ, почему именно этот кандидат идеально подходит под запрос клиента.

## Что реализовано
* **Двухэтапный пайплайн подбора:** Быстрая локальная фильтрация (Hard Filtering) отсекает заведомо неподходящих кандидатов, после чего LLM выполняет смысловое ранжирование.
* **Умная проверка календаря:** Система парсит `busy_dates` и строго отсеивает подрядчиков, занятых в запрошенную дату (в окне 23.09.2026 – 31.12.2026).
* **Генерация объяснений:** Интеграция с ИИ для написания 1-2 предложений, объясняющих совпадения по языку, формату, бюджету и специфике описания (без использования общих фраз).
* **Обработка краевых случаев (Edge Cases):** Три явно различимых исхода для пользователя: успешный подбор, отсутствие категории в городе, отсутствие свободных/подходящих кандидатов с вежливым текстовым объяснением причины отказа.
* **Детерминизм выдачи:** При одинаковых входных параметрах сервис всегда выдает один и тот же порядок карточек.

## Используемые технологии и архитектура
* **Frontend:** React 19, TypeScript, Tailwind CSS 4, Vite. Минималистичный UI, сфокусированный на качестве текстовой выдачи.
* **Backend:** Node.js (Express). Выполняет роль прокси-сервера и слоя бизнес-логики.
* **AI / LLM:** Google Gemini API (`@google/genai`, модель `gemini-3.8-flash`). Запросы выполняются с параметром `temperature: 0` для обеспечения строгого детерминизма.
* **Архитектура:** Клиент отправляет критерии поиска на сервер. Сервер локально фильтрует датасет по точным совпадениям (город, бюджет, календарь), берет топ-5 кандидатов и отправляет их в Gemini со строгим промптом. Gemini возвращает отформатированный JSON с ID победителей и объяснениями, которые сервер отдает клиенту.
